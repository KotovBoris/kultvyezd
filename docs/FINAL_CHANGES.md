# Ветка final-polish: что изменилось к финалу

Ветка собрана поверх `main` (тег `snapshot-2026-10-23-before-polish` — состояние до правок).
Перед защитой каждому стоит прочитать свой раздел: по регламенту команда должна
понимать и уметь объяснить весь код решения.

## Как посмотреть

- Стенд: https://213.193.198.71, бот @t158_hakaton_max_bot (выкачено из `final-polish`).
- В MAX: открыть бота → «Попробовать демо». Вы станете учителем демо-класса 7Б и
  родителем Тимура: виртуальные родители отвечают сами за минуту, двое молчат,
  чтобы можно было нажать «Напомнить».
- Локально: `backend` — `uvicorn app.main:app`, `miniapp` — `npm run dev`;
  вне MAX пользователь задаётся параметром `?user_id=…`.
- Тесты: `cd backend && python -m pytest -q` (201 тест), стенд — `scripts/e2e_docker.py`.

## Откат

- Код: `git checkout snapshot-2026-10-23-before-polish` (или выкатить `main`: `~/run.sh`).
- Сервер целиком (код, `.env`, `run.sh`, volume с базой, образы):
  `bash /root/backups/snapshot-20261023/rollback.sh`.

## Бэкенд (`backend/app`)

| Что | Где | Зачем |
|---|---|---|
| Кто делает запрос | `auth.py` | `X-Max-Init-Data` проверяется токеном бота, user_id берётся из подписи. Вне MAX — демо-режим с `?user_id`. |
| Демо-песочница | `demo.py` | Свой класс 7Б на каждого, виртуальные родители с задержкой, «живое демо» по QR: жюри становится родителями. |
| Подключение родителя | `main.py` `/classes/{id}/invite`, `/join` | Одна ссылка на класс; номер из `requestContact` с проверкой HMAC (`max_validate.verify_phone`). |
| Второй родитель | `/parent/second-invite`, `/parent/pair` | Одноразовая ссылка от первого родителя. |
| Юридическая модель | `UserProfile.terms_accepted_at`, `/me/accept-terms`, `/parent/revoke` | Соглашение о ПЭП (63-ФЗ ст. 9) и отдельное согласие на ПДн (152-ФЗ ст. 9), отказ — бумага. Без них ответ не принимается: API — 409, бот сначала показывает оба текста (`bot._ask_terms`). |
| Живое демо по QR | `demo.sandbox_invite_code`, `demo._add_extra_kid` | Ссылка демо-класса постоянная (не меняется после «Начать демо заново»), места хватает всему залу. |
| Файлы в чат MAX | `max_client.MaxClient` | Доверяем и российскому корню (API MAX), и публичным CA (сервер файлов `fu.oneme.ru`); пока MAX обрабатывает файл (`attachment.not.ready`), повторяем отправку. |
| Ответ на согласие | `services.apply_consent`, `/consent` | Отвечает только родитель ребёнка; учитель отмечает лишь бумажный бланк, его MAX ID в подпись не пишется. |
| Изменить ответ | `services.can_change_answer`, `/consent/reset` | Родитель — до начала выезда, учитель — свои бумажные отметки. |
| Напоминания | `services.due_auto_reminders` | Не раньше 6 ч после приглашения, только самое срочное, не с 21:00 до 08:00 МСК. |
| День выезда | `/attendance`, `/milestone`, `/cancel` | Перекличка, «выехали/вернулись» (повтор не рассылает), отмена с сообщением родителям. |
| Документы | `documents.py` | Проект приказа по письму 06-836, список, рабочий список с телефонами, реестр согласий с хешем текста, инструктаж и памятка, бланки, образец Порядка. |
| Бот | `bot.py` | Карточка «чей ребёнок, кто зовёт, сколько стоит, платить в чате не нужно», кнопки с именем ребёнка, квитанция, «Изменить ответ», документы в чат. |

## Мини-приложение (`miniapp/src`)

Интерфейс на `@maxhub/max-ui` (цвета, шрифт, тёмная тема MAX). Правила для родителей
40–70 лет: текст от 17 px, главная кнопка 56 px, статус словом + значком + цветом.

| Экран | Файл | Что важно |
|---|---|---|
| Приветствие | `Welcome.tsx` | Выбор роли и «Попробовать демо». |
| Учитель: главная | `TeacherHome.tsx` | Выезды впереди, прошедшие и отменённые отдельно, классы. |
| Новый выезд | `NewTrip.tsx` | 3 шага: афиша или своё событие → когда/как/помощник → «так увидят родители». |
| Выезд | `TripScreen.tsx` | Светофор, «Напомнить», списки, документы, бумажный бланк, день выезда, отмена. |
| Класс | `ClassScreen.tsx`, `NewClass.tsx` | Ссылка/QR для родителей, список из Excel или вставкой. |
| Родитель | `ParentHome.tsx`, `ParentTrip.tsx` | Соглашение в 2 шага, ответ одной кнопкой, квитанция, звонок учителю. |
| Подключение | `JoinScreen.tsx`, `PairScreen.tsx` | По ссылке класса и по ссылке второго родителя. |

## Что проверить руками перед защитой

1. Демо в MAX с телефона: приглашение в чате, «Да» → квитанция, светофор у учителя.
2. «Прислать документы в чат» — PDF открывается в MAX.
3. QR живого демо со слайда 5 ведёт в демо-класс.
