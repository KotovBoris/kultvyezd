# Сценарий демонстрации «ClassGo» (для защиты)

Готовый план показа. Две роли по шагам — **учитель** (сквозной путь) и **родитель**.
Укладывается в 6–8 минут; что говорить — в правой колонке.

## Подготовка (за 2 минуты до защиты)

```bash
cd kultvyezd
cp .env.example .env        # при необходимости впишите MAX_BOT_TOKEN
docker compose up -d --build
curl -s http://localhost:8080/healthz                       # проверка живости
curl -s -X POST http://localhost:8080/api/v1/admin/reset-demo   # чистое демо-состояние
```

Открыть **http://localhost:8080** (телефонный вьюпорт — Ctrl/Cmd+Shift+M).
Резервный вход без MAX: «Режим просмотра» внизу экрана — переключение на экран любого родителя
и сброс демо.

## Путь учителя: импорт → каталог → создание → публикация → дашборд → документы

| Шаг | Действие | Что говорим жюри |
|---|---|---|
| 1 | Открыть бота **@t158_hakaton_max_bot** в MAX, нажать «Начать» | «Вход строго через бота MAX: приветствие и нативная кнопка мини-приложения» |
| 2 | Вкладка **«Класс»**: загрузить `artifacts/sample_class_import.csv` | «Учитель заводит **свой** класс из интерфейса — CSV/XLSX, ФИО, даты рождения и телефоны родителей разбираются автоматически» |
| 3 | Показать результат импорта (`students_created`, `parents_created`, `skipped_rows`) | «Пустые строки отсеиваются, некорректные даты не ломают импорт» |
| 4 | Вкладка **«Каталог событий»**: включить «Пушкинская карта», сортировку по дате и пресет «на выходных» | «Это не просто афиша: есть сортировка, фильтр по дате и пресет „на выходных“» |
| 5 | Включить авто-фильтр **«подходит классу по возрасту»** | «Сервис сам считает возраст по датам рождения класса и убирает нерелевантные 12+/16+ — отличитель от любой афиши» |
| 6 | «Выбрать событие» → «Создать выезд» | «Весь класс добавлен автоматически со статусом „ожидает“; дата, время сбора/возвращения и дедлайн заданы» |
| 7 | На карточке выезда нажать **«Опубликовать в чат класса»** | «Карточка события уходит в чат класса одним сообщением — вместо 50–150 сообщений ругани» |
| 8 | Дашборд **«Светофор»**: 🟢/🟡/⚪/🔴, дедлайн-таймер (обратный отсчёт) | «Готовность класса видна в одном экране; таймер создаёт срочность „осталось N дн/ч“» |
| 9 | Поиск ученика и фильтр строк по статусу | «Класс 24+ человек — ищем и фильтруем без прокрутки» |
| 10 | «Напомнить не ответившим» | «Точечные пуши только GREY/YELLOW в личку, а не флуд в чат» |
| 11 | Экспорт **CSV** списка и **ICS**-календарь | «Список — туроператору/кассе; ICS снижает „проспали“» |
| 12 | **«Сформировать приказ (DOCX)»** с выбором приложений: маршрутный лист, уведомление ГИБДД, согласие на ПДн | «Пакет документов для автобусной перевозки — по ПП №1527 и 152-ФЗ, автоматически за секунды» |
| 13 | Показать экстренные телефоны и кнопку **отправки приказа файлом в чат** | «Безопасность в день выезда и доставка документа в чат класса» |

## Путь родителя: согласие с ПДн → билет → календарь → прозрачность

| Шаг | Действие | Что говорим жюри |
|---|---|---|
| 1 | Открыть экран родителя (в MAX или «Режим просмотра» → выбрать ребёнка; `?startapp=<id>`) | «Родитель попадает на свой экран из чата» |
| 2 | Переключить ребёнка (если у родителя несколько детей) | «Родитель с двумя детьми видит **всех** и переключается — не только первого» |
| 3 | Показать блок **согласия на обработку ПДн** и шаг подтверждения ПЭП | «Согласие осознанное: без предотмеченных галочек, с подтверждением; фиксируется дата, время, подписант» |
| 4 | Нажать «✅ Отпускаю ребёнка» (или «❌ Не сможет поехать» + причина) | «Подтверждение участия в 1 клик; повторное нажатие идемпотентно, „два родителя“ не перезаписывают решение» |
| 5 | Отметить **«Билет куплен»** и ввести **номер билета** | «Билет покупается в кассе музея, сервис хранит только статус и номер — денег не касается» |
| 6 | Нажать **«Добавить в календарь (ICS)»** | «Стандарт билетных сервисов — снижает „забыли и проспали“» |
| 7 | Открыть блок **«Что взять с собой»** | «Родитель собирает ребёнка вечером — памятка под рукой» |
| 8 | Открыть экран **прозрачности ПДн/ПЭП** | «Прямой ответ на главный страх администрации и родителей: кто видит данные, где хранятся, что такое ПЭП» |
| 9 | Вернуться в «Светофор» учителя — статус изменился | «Сбор группы вместо 4–7 дней занимает часы» |

### Резерв, если нужен 30-секундный вариант
Шаги учителя 2 → 6 → 7 → 12 (импорт, каталог с авто-возрастом, создание, публикация, приказ) и
шаги родителя 3 → 4 → 5 (ПДн-согласие, согласие, билет).

## Ключевые фразы для жюри

- «Сервис **не касается денег** — оплата напрямую в кассу музея (снятие риска „поборов“, 273-ФЗ)».
- «Данные каталога — **модельные** (снапшот, поле `source`); реальная интеграция с PRO.Культура.РФ — следующий шаг».
- «**Пушкинская карта индивидуальна** (14–22): билет покупает каждый родитель отдельно, групповой оплаты по ПК нет — мы это честно показываем, а не обещаем».
- «**ПЭП** фиксирует факт и время согласия; для пилота равнозначность бумаге даёт локальный акт школы — это допущение, а не квалифицированная подпись».
- «**324 автотеста** (pytest 189 · vitest 83 · E2E-эмулятор MAX 15 · docker-стек 19 · Playwright 18) проходят одной командой `./scripts/run_all_tests.sh`; есть CI».
- «Производительность: начальный JS **−70%**, CSS **−95%**, CLS 0 — цифры и бюджеты в [`PERFORMANCE.md`](PERFORMANCE.md)».

## Если показываем живой MAX

- Бот уже подключён (polling), **команды зарегистрированы** (`start`/`trips`/`help`).
- Для кнопки «Открыть приложение» нужен публичный HTTPS-адрес mini-app (указать в настройках бота).
- Если токена/сети нет — показать запись экрана мини-приложения (вне MAX всё работает).
