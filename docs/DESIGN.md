# DESIGN.md — дизайн-контракт «КультВыезд»

Формат: Google DESIGN.md (открытый формат, который используют дизайн-инструменты).
Задача файла — зафиксировать одно направление так, чтобы **все экраны строились из него**,
а не «дорисовывались» по вкусу (иначе возникает AI design-system drift).

---

## 0. Почему это важно (контекст анти-слоп)

Прогнали наш интерфейс через сканер «AI-теллов» (`avoid-ai-design`, `scripts/detect.mjs`).
Найдено **5 сигналов**, из них **P0**:

| Код | Что нашли | Почему это «писал агент» |
|---|---|---|
| **C1 P0** | Фиолетово-бирюзовый градиент (`#6C4CF1 → #2FB3C7`) | канонический «невыбранный» градиент из семейства Tailwind indigo |
| **C2 P1** | Фиолетовая основная кнопка `#6c4cf1` (hue 252°) | акцент «по умолчанию», а не по смыслу |
| **T1 P0** | Системный шрифт (`-apple-system, …`) без второй гарнитуры | значит шрифт не выбирали |
| I2 P1 | Emoji вместо иконок (`🟢 🔴 ✅ ❌ ⬇`) | эмодзи в интерфейсе = нет иконографии |
| L4 P1 | Лента абстрактных метрик | «доказательство ради доказательства» |

Цель: заменить дефолты осознанными решениями.

## 1. Grounding — из чего сделан мир продукта

| Вопрос | Ответ |
|---|---|
| Что это и для кого? | Сервис организации школьных культурных выездов. Основной пользователь — **классный руководитель**; вторичный — родитель |
| Из чего мир сделан? | Школьные бумаги: **приказ на бланке, ведомость класса, классный журнал, бланк согласия**, печать/штамп. И билет в музей |
| Что этот мир печатает? | Списки с **нумерацией строк**, официальные бланки с линиями-разделителями, отметки в журнале, печати |
| Самое характерное? | **Ведомость**: список класса из 24 имён с отметками. «Светофор» — это табель с отметками |
| Что сделал бы конкурент? | Обычный SaaS-дашборд: центрированный заголовок, три карточки, фиолетовый акцент — это и есть дефолт |

**Вывод:** это не SaaS, это **цифровой бланк**. Интерфейс должен читаться как аккуратно
заполненный официальный документ, а не как маркетинговый лендинг.

## 2. Направление: «Ведомость» (Class Register)

Сочетание **Editorial** (документ, типографика) и **Industrial/utilitarian** (плотность,
таблица, читаемость). Не костюм «broadsheet» (там правила ради вида) — здесь линии и сетка
происходят из структуры самого бланка.

### Палитра (4 цвета + статусные)

Цвет берём из мира документа: **бумага, чернила, служебная печать**. Никакого
cream+terracotta (SD1) и никакого near-black+acid green (SD2).

| Роль | Токен | Значение | Откуда взято |
|---|---|---|---|
| Бумага (фон) | `--paper` | `#F4F5F3` — холодновато-бумажный, чуть зелёный | сероватая бумага бланка, не пергамент |
| Лист (поверхность) | `--sheet` | `#FFFFFF` | чистый лист для бланка |
| Чернила (текст) | `--ink` | `#171A1F` — почти чёрный, нейтральный | печатные чернила |
| Приглушённое | `--ink-2` | `#5C6470` | подписи, служебные поля |
| Линия бланка | `--rule` | `#D3D7DD` | линии-разделители в бланке |
| **Служебная печать** | `--stamp` | `#B3261E` — тёмно-красный (печать/штамп) | красная печать школы — единственный «брендовый» цвет |
| Чернильно-синий | `--link` | `#1F3A5F` | синие чернила ручки (ссылки/служебное) |

**Статусные цвета — не декор, а смысл** (это и есть «Светофор»):
`--ok #1F7A4C` (зелёный), `--wait #B4791A` (янтарный), `--idle #8A9099` (серый),
`--stop #B3261E` (красный, совпадает с печатью — семантически верно: отказ = тревога).

Правило: акцент `--stamp` используется **редко** — только для главного действия
и для штампа-отметки. Основную работу несут чернила и сетка.

### Типографика

Кириллица обязательна. Выбираем две гарнитуры с разделением ролей:

| Роль | Гарнитура | Почему |
|---|---|---|
| Заголовки и текст | **Golos Text** (400/500/600/700) | создан для государственных сервисов РФ: «официально, но современно», отличная кириллица. Осознанный выбор под наш домен, а не Inter |
| Числа, даты, ID, номера билетов | **JetBrains Mono** (400/500) | табличные данные, где важна разрядность и выравнивание. Mono — по делу (данные), а не как декор |

Оба — с самохостингом (woff2 в `public/fonts`), чтобы не зависеть от внешнего CDN на стенде.

Масштаб: 12 / 13 / 15 / 18 / 24 / 32. Заголовки — **sentence case**, без ALL-CAPS.
Никаких «одно слово в заголовке цветным» (SD5).

### Сетка и layout

- **Не центрируем.** Заголовки прижаты влево, как в бланке.
- **Радиус: 2px** (почти прямые углы). Скругление `rounded-2xl` — маркер дефолта.
- **Линии, а не тени.** Разделители — `1px var(--rule)`. Тени не используем.
- **Ведомость** — ключевой паттерн: строки с номером (№ 1…24), плотные, hairline-разделители.
- Плотность: 8px базовый шаг, компактные строки таблицы (как в журнале).

### Движение (motion)

Скупое и функциональное, с уважением к `prefers-reduced-motion`:
- **Штамп**: отметка статуса появляется с лёгким «прижатием» (scale 1.06 → 1, 120 мс) — как печать.
- **Строка ведомости**: подсветка слева 2px при наведении (мгновенно).
- Никакого fade-up на каждом блоке (M1), никакого bounce.

### Signature detail (одна яркая деталь)

**Печать-отметка.** Статус ребёнка — не цветной бейдж-пилюля, а **штамп**: текст в рамке
с лёгким поворотом (`rotate(-1.2deg)`), как настоящая отметка в документе. Это узнаваемая
деталь, которой нет у типового SaaS-дашборда.

## 3. Проверка плана против дефолтов второго порядка

| Ход | Вопрос «сделал бы для любой страницы?» | Решение |
|---|---|---|
| Бумажный фон | бумага нейтрально-холодная, не `#F4F1EA`, акцент не terracotta | ✅ не SD1 |
| Служебный акцент | тёмно-красная печать — из мира документа, не emerald/acid | ✅ не SD2/SD8 |
| Hairline + 2px радиус | линии = структура бланка, а не «broadsheet cosplay» | ✅ оправдано (SD3 не срабатывает: у нас документ, не газета) |
| Mono | только для чисел/дат/номеров — там, где читают данные | ✅ не SD4 |
| Заголовки | sentence case, без акцентного слова | ✅ не SD4/SD5 |
| Статусы | семантические цвета светофора, есть смысл | ✅ не декоративный акцент |

## 4. Как это проверяется

1. `node _tools/avoid-ai-design/scripts/detect.mjs miniapp/src` — должен стать **0 P0/P1**.
2. Скриншоты Playwright до/после — визуально сравнить.
3. `axe-core` — доступность не ниже, чем была (контраст статусных цветов ≥ 4.5:1).
4. Тест «силуэта»: уменьшить экран до ч/б блоков — композиция не должна совпасть
   с типовым дашбордом.
